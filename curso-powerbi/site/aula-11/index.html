01O desafio do negócio: Café Grão de Ouro

Na prática, os dados vêm em formatos variados e pastas com arquivos mensais.

A rede Café Grão de Ouro possui 4 lojas no estado de São Paulo e precisa de um painel gerencial moderno para acompanhar suas vendas. Cada mês de vendas é gerado pelo PDV como um arquivo CSV separado dentro da pasta Vendas. O cadastro das lojas é um arquivo texto exportado do sistema e o catálogo de produtos é uma planilha CSV.

Por que este projeto é essencial

Saber consolidar pastas de arquivos CSV e combinar com fontes TXT é uma das habilidades mais solicitadas no mercado. O relatório se mantém sozinho mês a mês sem retrabalho de copiar e colar.

02Baixe os arquivos da aula

Extraia o pacote de arquivos em uma pasta fixa no seu computador.

  1. Baixe o arquivo Aula4_Cafeteria_Alunos.zip pelo botão acima.
  2. Clique com o botão direito no arquivo baixado → Extrair Tudo….
  3. Escolha uma pasta fixa no seu computador (por exemplo: C:\CursoPowerBI\Cafeteria).
  4. Abra a pasta extraída e certifique-se de que vê a pasta Aula4_Cafeteria com seus arquivos: Lojas.txt, Produtos.csv, Tema_Cafeteria.json, a pasta Vendas e a pasta Novos_Dados.

Atenção ao caminho

Não mantenha os arquivos dentro do arquivo compactado (.zip) nem na pasta Downloads temporária. O Power BI precisa de um caminho de pasta permanente para ler os arquivos.

03Importando múltiplos CSVs via Pasta

Automatize a consolidação de todos os meses em uma única tabela fato.

  1. No Power BI Desktop, clique em Página Inicial → Obter Dados → Mais….
  2. Selecione a categoria Tudo ou Arquivo e clique em Pasta → Conectar.
  3. Clique em Procurar… e aponte para a subpasta Aula4_Cafeteria\Vendas.
  4. Clique em OK. A janela mostrará a lista dos 8 arquivos CSV (Vendas_2026_01.csv a Vendas_2026_08.csv).
  5. Clique na setinha de Combinar e selecione Combinar e Transformar Dados.
  1. Na janela de visualização da combinação, verifique se o Delimitador está como Ponto e vírgula.
  2. Origem do arquivo: 65001: UTF-8 (para preservar eventuais caracteres).
  3. Clique em OK. O Power Query criará automaticamente o grupo auxiliar de parâmetros e abrirá a consulta combinada.
  1. Renomeie a consulta de Vendas para fVendas.
  2. A primeira coluna gerada pelo Power BI é Source.Name (o nome do arquivo). Você pode removê-la: clique com o botão direito no cabeçalho dela → Remover.
  3. Verifique e ajuste a tipagem de cada coluna no ícone ao lado do nome:
    • Data: Data
    • ID_Loja: Número Inteiro
    • ID_Produto: Número Inteiro
    • Quantidade: Número Inteiro
    • Valor_Total: Número Decimal
M · fVendas (resumo da consulta)
let
    Fonte = Folder.Files("C:\CursoPowerBI\Cafeteria\Vendas"),
    ArquivosCSV = Table.SelectRows(Fonte, each ([Extension] = ".csv")),
    Combinado = Table.Combine(Table.AddColumn(ArquivosCSV, "Dados", each Csv.Document([Content], [Delimiter=";", Columns=5, Encoding=65001, QuoteStyle=QuoteStyle.None]))[Dados]),
    Cabecalhos = Table.PromoteHeaders(Combinado, [PromoteAllScalars=true]),
    TipoAlterado = Table.TransformColumnTypes(Cabecalhos,{{"Data", type date}, {"ID_Loja", Int64.Type}, {"ID_Produto", Int64.Type}, {"Quantidade", Int64.Type}, {"Valor_Total", Currency.Type}})
in
    TipoAlterado
✓
Confira os dados

A tabela fVendas possui agora o histórico consolidado de 8 meses sem nenhuma duplicação de cabeçalhos.

04Importando Lojas (TXT) e Produtos (CSV)

Adicione as duas tabelas dimensão com seus respectivos delimitadores.

  1. Ainda no Power Query, clique em Nova Fonte → Texto/CSV.
  2. Selecione o arquivo Lojas.txt.
  3. O Power BI detectará automaticamente o delimitador como Tabulação. Verifique as 4 colunas: ID_Loja, Loja, Cidade e Bairro.
  4. Clique em OK.
  5. Renomeie a consulta para dLojas.
  6. Defina ID_Loja como Número Inteiro e as demais colunas como Texto.
  1. Clique em Nova Fonte → Texto/CSV.
  2. Selecione o arquivo Produtos.csv.
  3. Verifique o delimitador como Ponto e vírgula e codificação UTF-8.
  4. Clique em OK.
  5. Renomeie a consulta para dProdutos.
  6. Ajuste a tipagem: ID_Produto como Número Inteiro, Produto e Categoria como Texto, e Preco como Número Decimal (ou Moeda).
i

Pronto! Temos agora a tabela fato fVendas e as duas dimensões dLojas e dProdutos prontas e limpas. Clique em Fechar e Aplicar.

05Modelo estrela e tabela dCalendario

Crie a tabela de datas e conecte as chaves no diagrama de modelo.

Na exibição de Relatório ou Tabela, clique em Modelagem → Nova Tabela e insira a fórmula:

DAX · Tabela Calculada
dCalendario =
VAR MinData = DATE ( 2026, 1, 1 )
VAR MaxData = DATE ( 2026, 12, 31 )
RETURN
    ADDCOLUMNS (
        CALENDAR ( MinData, MaxData ),
        "Ano", YEAR ( [Date] ),
        "Mês Num", MONTH ( [Date] ),
        "Mês", FORMAT ( [Date], "mmm", "pt-BR" ),
        "Mês Ano", FORMAT ( [Date], "mmm/yy", "pt-BR" ),
        "AnoMês Num", YEAR ( [Date] ) * 100 + MONTH ( [Date] ),
        "Dia da Semana", FORMAT ( [Date], "ddd", "pt-BR" ),
        "Dia Semana Num", WEEKDAY ( [Date], 2 ),
        "Trimestre", "T" & FORMAT ( [Date], "q" )
    )
  1. Selecione a coluna Mês → Classificar por coluna → Mês Num.
  2. Selecione a coluna Mês Ano → Classificar por coluna → AnoMês Num.
  3. Clique com o botão direito em dCalendario → Marcar como tabela de datas → selecione Date.

Clique no ícone de Modelo (terceiro ícone à esquerda) e posicione fVendas no centro e as dimensões ao redor (modelo estrela):

  • dLojas[ID_Loja] (1) ───> (*) fVendas[ID_Loja]
  • dProdutos[ID_Produto] (1) ───> (*) fVendas[ID_Produto]
  • dCalendario[Date] (1) ───> (*) fVendas[Data]
✓
Padrão 1 para Muitos

Todos os relacionamentos devem estar com cardinalidade 1 para muitos (1:*) e direção de filtro único (da dimensão para a fato).

06Aplicando o tema JSON da Cafeteria

Importe as cores personalizadas do Café Grão de Ouro com um clique.

  1. Na faixa de opções, clique na guia Exibição.
  2. Abra o menu de temas clicando na setinha para baixo na galeria de temas.
  3. Clique em Procurar temas.
  4. Navegue até a pasta Aula4_Cafeteria e selecione Tema_Cafeteria.json.
  5. O Power BI exibirá a mensagem: "Tema importado com êxito".
i
O que o tema altera

A paleta passa a usar marrom café (#6F4E37), dourado (#C8A27A) e verde floresta (#2E7D6B), o fundo da página ganha tom suave (#F6F1EB) e os novos visuais já nascem com cantos arredondados de 14px e sombras sutis.

07Criando as medidas DAX essenciais

Crie uma tabela dedicada _Medidas e escreva os principais KPIs do negócio.

Clique em Página Inicial → Inserir Dados, dê o nome de _Medidas à tabela e clique em Carregar.

DAX
Faturamento Total =
SUM ( fVendas[Valor_Total] )

Formate como Moeda (R$) com 2 casas decimais.

DAX
Total Unidades Vendidas =
SUM ( fVendas[Quantidade] )

Formate como Número Inteiro com separador de milhar.

DAX
Qtd de Vendas =
COUNTROWS ( fVendas )

Cada linha na fato representa uma venda realizada no balcão.

DAX
Ticket Médio =
DIVIDE ( [Faturamento Total], [Qtd de Vendas], 0 )

Formate como Moeda (R$).

DAX
Preço Médio por Item =
DIVIDE ( [Faturamento Total], [Total Unidades Vendidas], 0 )

08Montagem do Dashboard Executivo

Organize a hierarquia visual com cartões de KPIs, gráficos e segmentações.

Crie 4 visuais de Cartão (ou Cartão de Linha Múltipla / Novo Cartão) alinhados na primeira linha da página:

  1. Faturamento Total: R$ no total do período
  2. Unidades Vendidas: volume total de cafés e lanches consumidos
  3. Qtd de Vendas: total de atendimentos realizados
  4. Ticket Médio: gasto médio por pedido
  1. Insira um Gráfico de Linhas.
  2. Eixo X: dCalendario[Mês] ou dCalendario[Mês Ano].
  3. Eixo Y: [Faturamento Total].
  4. Ative Rótulos de dados para visualizar os valores pico de faturamento em cada mês.
  1. Gráfico de barras horizontais: Eixo Y com dProdutos[Categoria] e Eixo X com [Faturamento Total].
  2. Gráfico de colunas: Eixo X com dLojas[Loja] e Eixo Y com [Faturamento Total].
  3. Adicione uma Segmentação de Dados lateral com dLojas[Cidade] e dProdutos[Categoria] para filtragem interativa rápida.

09Testando a atualização dinâmica com novos dados

Veja o poder da automação: o mês de setembro chega e é integrado em segundos.

  1. Observe os números atuais do seu dashboard (anote o Faturamento Total acumulado até agosto).
  2. Abra o explorador de arquivos do Windows na pasta Aula4_Cafeteria.
  3. Entre na pasta Novos_Dados e copie o arquivo Vendas_2026_09.csv.
  4. Cole o arquivo dentro da pasta Aula4_Cafeteria\Vendas (onde já estão os arquivos de janeiro a agosto).
  1. Volte ao Power BI Desktop.
  2. Na guia Página Inicial, clique no botão Atualizar.
  3. O Power BI reexecutará a leitura da pasta Vendas, encontrará o 9º arquivo automaticamente, promoverá cabeçalhos, tipará os dados e atualizará todos os gráficos.
  4. O mês de setembro (Set/26) aparecerá instantaneamente no gráfico de linhas com seus números consolidados!
✓
Sucesso da automação

Esse é o fluxo de trabalho profissional do Power BI: você cria a estrutura uma vez e o relatório acompanha o crescimento do negócio sem exigir reconstrução.

10Atividades práticas

  1. Atividade 1: Crie uma medida DAX chamada Faturamento Cafés utilizando a função CALCULATE para filtrar apenas os produtos da categoria "Cafés".
  2. Atividade 2: Monte uma matriz comparando cada Loja com suas vendas por Categoria e aplique formatação condicional de barras de dados na coluna de Faturamento.
  3. Atividade 3: Crie uma segmentação de dados em formato de blocos para alternar entre as 4 lojas com um único clique.
