01Como o DAX pensa: os dois contextos

Se você entender esta seção, o resto da aula fica fácil.

Contexto de filtro

É o conjunto de filtros ativos quando a medida é calculada: a barra do gráfico (Marca = Apple), a segmentação (Ano = 2021), o filtro da página. A medida [Faturamento Total] é a mesma fórmula; o contexto de filtro é que muda o resultado.

Contexto de linha

Existe quando o DAX percorre uma tabela linha a linha: em colunas calculadas e dentro de iteradores (SUMX, AVERAGEX, FILTER, RANKX). Em cada linha, você pode ler os valores daquela linha: fVendas[Qtd Vendida] * RELATED(dProdutos[Preço Unitario]).

Contexto de filtroContexto de linha
Vem deVisuais, segmentações, filtros, CALCULATEColunas calculadas e iteradores
Responde“Quais linhas da fato entram na conta?”“Qual é o valor desta linha?”

Transição de contexto

Quando você chama uma medida dentro de um contexto de linha (dentro de SUMX, ou numa coluna calculada), o DAX transforma a linha atual em filtro. É isso que faz AVERAGEX(VALUES(dClientes[ID Cliente]), [Faturamento Total]) calcular o faturamento de cada cliente.

02CALCULATE: mudando o contexto de filtro

CALCULATE avalia uma expressão depois de adicionar, trocar ou remover filtros.

DAX
Faturamento Notebook =
CALCULATE ( [Faturamento Total], dProdutos[Categoria] = "Notebook" )
✓
Confira

R$ 7.469.356,74 no total. Num gráfico por ano, cada barra mostra só o notebook daquele ano.

Repare: se o visual já tiver um filtro de categoria (Celular, por exemplo), o CALCULATE substitui esse filtro e mostra Notebook mesmo assim. Para respeitar o filtro existente, use KEEPFILTERS(dProdutos[Categoria] = "Notebook").

DAX
Faturamento Produtos Premium =
CALCULATE (
    [Faturamento Total],
    FILTER ( dProdutos, dProdutos[Preço Unitario] >= 2000 )
)

FILTER percorre dProdutos e devolve só os produtos com preço a partir de R$ 2.000. Use FILTER quando a condição for mais complexa que “coluna = valor”.

i

Prefira filtrar a dimensão (dProdutos, 293 linhas) e não a fato (56 mil linhas). O resultado é o mesmo e o cálculo é muito mais rápido.

DAX
% Faturamento Total Geral =
DIVIDE (
    [Faturamento Total],
    CALCULATE ( [Faturamento Total], ALL ( dProdutos ) )
)
✓
Confira

Notebook = 49,1% · Celular = 29,1% · Apple (por marca) ≈ 29%.

DAX
% na Categoria =
DIVIDE (
    [Faturamento Total],
    CALCULATE ( [Faturamento Total], ALLEXCEPT ( dProdutos, dProdutos[Categoria] ) )
)

Numa matriz Categoria → Produto, cada produto mostra quanto representa dentro da sua categoria. ALLEXCEPT remove todos os filtros de dProdutos, menos o de Categoria.

DAX
% do Selecionado =
DIVIDE (
    [Faturamento Total],
    CALCULATE ( [Faturamento Total], ALLSELECTED ( dProdutos ) )
)
FunçãoRemoveTotal de referência
ALL / REMOVEFILTERSTodos os filtros da tabela/colunaEmpresa inteira
ALLEXCEPTTodos, menos as colunas indicadasO grupo (ex.: a categoria)
ALLSELECTEDFiltros do próprio visual, mas respeita segmentaçõesO que o usuário selecionou
?
Qual usar

Pergunte: “percentual em relação a quê?”. Da empresa toda → ALL. Do grupo → ALLEXCEPT. Do que o usuário filtrou → ALLSELECTED.

03Iteradores: X no fim do nome

SUMX, AVERAGEX, MAXX, MINX e COUNTX percorrem uma tabela e agregam uma expressão.

DAX
Faturamento Médio por Cliente =
AVERAGEX ( VALUES ( fVendas[ID Cliente] ), [Faturamento Total] )

VALUES devolve a lista de clientes no contexto; para cada um, [Faturamento Total] é calculado (transição de contexto) e depois tirada a média.

?
Por quê

Ticket médio por pedido (aula 5) e por cliente são coisas diferentes. Um cliente que compra 5 vezes tem ticket por pedido baixo e valor por cliente alto. Os dois juntos contam a história.

DAX
Maior Pedido =
MAXX ( VALUES ( fVendas[Ordem de Compra] ), [Faturamento Total] )
DAX
Lucro por Pedido =
VAR Lucro   = [Faturamento Total] - [Custo Total]
VAR Pedidos = [Nº Pedidos]
RETURN
    DIVIDE ( Lucro, Pedidos )

Cada VAR é calculada uma vez e pode ser reutilizada. Fica mais fácil de ler, de depurar (troque o RETURN por uma variável para testar) e mais rápido.

04Rankings e Top N

DAX
Ranking Produto =
IF (
    HASONEVALUE ( dProdutos[Produto] ),
    RANKX ( ALLSELECTED ( dProdutos[Produto] ), [Faturamento Total], , DESC, Dense )
)
✓
Confira

1º Notebook Asus ROG Zephyrus Duo 15 - Prata (R$ 1.021.854,00), 2º Dell Gamer G11-i1000 - Amarelo, 3º Teclado sem fio V320 - Preto.

Com ALLSELECTED, o ranking se refaz quando você filtra uma categoria: o melhor celular vira 1º entre os celulares.

DAX
Faturamento Top 10 Produtos =
CALCULATE (
    [Faturamento Total],
    TOPN ( 10, ALL ( dProdutos[Produto] ), [Faturamento Total], DESC )
)

% Top 10 =
DIVIDE ( [Faturamento Top 10 Produtos], [Faturamento Total] )
?
Por que importa

Se 10 produtos (de 293) fazem boa parte do faturamento, a empresa depende de poucos itens. Ruptura de estoque num deles vira prejuízo grande. É o princípio de Pareto (80/20).

DAX
Faixa de Margem =
VAR M = [Margem %]
RETURN
    SWITCH (
        TRUE (),
        ISBLANK ( M ), BLANK (),
        M >= 0.75, "Alta",
        M >= 0.65, "Média",
        "Baixa"
    )

SWITCH(TRUE(), condição1, resultado1, …, senão) é o “SE aninhado” bem escrito. Coloque numa tabela por categoria: Notebook e Celular saem “Alta”; Casaco e Camisa (55–58%), “Baixa”.

05Meta x Realizado

Usa a fMetas e a dCategoria criadas na aula 9.

DAX
Meta = SUM ( fMetas[Meta] )

% Atingimento = DIVIDE ( [Faturamento Total], [Meta] )

Diferença p/ Meta = [Faturamento Total] - [Meta]

Status Meta =
VAR A = [% Atingimento]
RETURN
    SWITCH ( TRUE (), ISBLANK ( A ), BLANK (), A >= 1, "✔ Atingiu", A >= 0.9, "▲ Perto", "▼ Abaixo" )
  1. Filtre a página para 2022 (as metas são de jan a jun/2022).
  2. Matriz: Linhas = dCategoria[Categoria]; Colunas = dCalendario[Mês]; Valores = Faturamento Total, Meta, % Atingimento.
  3. Formatação condicional em % Atingimento: Cor da tela de fundo → Regras: < 90% vermelho claro, 90–100% amarelo, ≥ 100% verde claro.
!
Atenção

Use dCategoria nas linhas, e não dProdutos[Categoria]. Só a dCategoria filtra as duas fatos (vendas pelo caminho dCategoria → dProdutos → fVendas, e metas direto).

?
Por que importa

Faturamento sozinho não diz se foi bom. R$ 1 Mi é ótimo se a meta era R$ 800 mil e péssimo se era R$ 1,5 Mi. Meta é o que dá contexto ao número.

06Títulos dinâmicos com SELECTEDVALUE

DAX
Título Dinâmico =
VAR Cat = SELECTEDVALUE ( dProdutos[Categoria], "todas as categorias" )
VAR Ano = SELECTEDVALUE ( dCalendario[Ano], "todos os anos" )
RETURN
    "Faturamento de " & Cat & " em " & Ano & ": " & FORMAT ( [Faturamento Total], "R$ #,##0" )

No visual: Formato → Geral → Título → botão fx → Formatar estilo: Valor do campo → escolha a medida Título Dinâmico.

i
SELECTEDVALUE(coluna, alternativo) devolve o valor se houver exatamente um selecionado; senão, devolve o alternativo.

07Erros comuns

“Uma função CALCULATE foi usada em uma expressão True/False…”

Você colocou uma medida dentro de um filtro booleano (dProdutos[Preço] > [Média]). Use FILTER: FILTER(dProdutos, dProdutos[Preço Unitario] > [Média]), ou guarde a medida numa VAR antes.

O ranking mostra 1 para todo mundo

Faltou o ALL/ALLSELECTED no primeiro argumento do RANKX. Sem ele, cada linha compara o produto só com ele mesmo.

O total da matriz não bate com a soma das linhas

Normal em medidas de razão (margem, %, médias): o total é recalculado no contexto do total, não somado. Se precisar da soma, use SUMX(VALUES(...), [Medida]).

% Atingimento vazio em 2020 e 2021

Correto: só existem metas para 2022.

08Atividades

A1 · Três percentuais

Básico

Numa matriz Categoria → Marca, mostre lado a lado: % Faturamento Total Geral, % na Categoria e % do Selecionado. Mude a segmentação de ano e explique o que muda em cada coluna.

A2 · Clientes que compraram notebook

Básico

Crie Clientes Notebook = CALCULATE([Clientes Ativos], dProdutos[Categoria] = "Notebook"). Quantos são em cada ano?

A3 · Top 3 marcas por categoria

Intermediário

Crie o ranking de marcas dentro da categoria (RANKX(ALLSELECTED(dProdutos[Marca]), ...)) e use o painel Filtros para mostrar só ranking ≤ 3.

A4 · Curva ABC

Desafio

Classifique os produtos em A (até 80% do faturamento acumulado), B (80–95%) e C (resto).

Dica
DAX
Faturamento Acumulado Produto =
VAR FatAtual = [Faturamento Total]
RETURN
    CALCULATE (
        [Faturamento Total],
        FILTER ( ALLSELECTED ( dProdutos[Produto] ), [Faturamento Total] >= FatAtual )
    )

Classe ABC =
VAR Pct = DIVIDE ( [Faturamento Acumulado Produto], CALCULATE ( [Faturamento Total], ALLSELECTED ( dProdutos[Produto] ) ) )
RETURN SWITCH ( TRUE (), Pct <= 0.8, "A", Pct <= 0.95, "B", "C" )

A5 · Painel de metas

Entrega

Crie a página “Metas 2022” com: cartões de Meta, Realizado e % Atingimento; a matriz com formatação condicional; um gráfico de colunas e linha (Faturamento em colunas, Meta em linha) por mês; e um título dinâmico.

09Resumo da aula

  • Contexto de filtro decide quais linhas entram; contexto de linha lê a linha atual.
  • CALCULATE adiciona ou troca filtros; ALL, ALLEXCEPT e ALLSELECTED removem.
  • Iteradores (X) percorrem tabelas; medidas dentro deles fazem transição de contexto.
  • RANKX com ALL/ALLSELECTED; TOPN para “os N maiores”.
  • SWITCH(TRUE()) para classificações; VAR para clareza.
  • Meta dá contexto ao faturamento.
