01O que é DAX

Sequência da aula: entender DAX → criar medidas → criar colunas calculadas → usar os cálculos em gráficos.

DAX (Data Analysis Expressions) é a linguagem de fórmulas do Power BI. Ela lembra as fórmulas do Excel, mas trabalha com tabelas e colunas em vez de células.

i
Vírgula ou ponto e vírgula?

Os exemplos usam vírgula para separar argumentos, que é o padrão do Power BI. Se o seu Power BI estiver configurado para separadores regionais (Arquivo → Opções → Configurações regionais), use ponto e vírgula: DIVIDE([A]; [B]).

02Primeiras medidas

Medida é um cálculo que o Power BI refaz para cada filtro do relatório. Ela não cria coluna na tabela.

Em Página Inicial → Inserir dados, crie uma tabela chamada _Medidas e clique em Carregar. Toda medida nova vai morar ali. O “_” faz a tabela aparecer no topo do painel Dados.

Selecione a tabela _Medidas → Modelagem → Nova medida. Digite na barra de fórmulas e pressione Enter:

DAX
Quantidade Vendida =
SUM ( BaseVendas[Qtd Vendida] )

Teste: insira um visual Cartão e arraste a medida para ele. Aparece o total de unidades vendidas.

DAX
Quantidade de Pedidos =
DISTINCTCOUNT ( BaseVendas[Ordem de Compra] )
?
Por que não SUM

Ordem de Compra é um código, não uma quantidade. E um mesmo pedido aparece em várias linhas quando tem vários produtos. DISTINCTCOUNT conta os valores diferentes: quantos pedidos existem de fato.

DAX
Clientes =
DISTINCTCOUNT ( BaseVendas[ID Cliente] )

Responde: quantos clientes diferentes compraram? Repare que contamos na fato: só entra quem comprou no período filtrado. Contar no CadastroClientes daria todos os cadastrados, mesmo quem nunca comprou.

Crie três cartões lado a lado: Quantidade Vendida, Quantidade de Pedidos e Clientes. Para o faturamento, falta uma informação: o preço está em CadastroProdutos, não na BaseVendas. Vamos buscá-lo.

03Colunas calculadas e RELATED

Coluna calculada faz um cálculo para cada linha da tabela e grava o resultado.

QtdPreçoFaturamento (linha a linha)
2100200
1500500
350150

Selecione a tabela BaseVendas (na exibição Tabela fica mais fácil ver o resultado) → Ferramentas da tabela → Nova coluna:

DAX
Preço de Venda =
RELATED ( CadastroProdutos[Preço Unitario] )

Leia assim: “para esta linha da BaseVendas, procure o produto relacionado em CadastroProdutos e traga o Preço Unitario”. É o PROCV do Power BI, só que usando o relacionamento.

!
Atenção

Se o preço aparecer 100 vezes maior (2595 em vez de 25,95), o tipo foi convertido errado no Power Query. Veja o passo 6 da aula 6: “Alterar Tipo → Usando a Localidade → Inglês (EUA)”.

DAX
Faturamento =
BaseVendas[Qtd Vendida] * BaseVendas[Preço de Venda]
DAX
Custo de Venda =
RELATED ( CadastroProdutos[Custo Unitario] )

Custo Total Linha =
BaseVendas[Qtd Vendida] * BaseVendas[Custo de Venda]

Crie cada coluna separadamente (uma fórmula por vez).

04Medidas de faturamento e rentabilidade

Agora transformamos os valores linha a linha em indicadores.

DAX
Faturamento Total =
SUM ( BaseVendas[Faturamento] )

Repare: a coluna Faturamento existe em cada linha; a medida Faturamento Total soma o que estiver filtrado.

DAX
Custo Total =
SUM ( BaseVendas[Custo Total Linha] )

Lucro Total =
[Faturamento Total] - [Custo Total]

Medidas podem usar outras medidas, sempre entre colchetes e sem nome de tabela.

DAX
Margem % =
DIVIDE ( [Lucro Total], [Faturamento Total], 0 )

Ticket Médio =
DIVIDE ( [Faturamento Total], [Quantidade de Pedidos], 0 )

Formate: selecione a medida → Ferramentas de medida → Margem % como Porcentagem; Ticket Médio e as de valor como Moeda (R$) com 2 casas.

?
Por que DIVIDE

Com a barra (/), uma divisão por zero dá erro e o visual quebra. DIVIDE(numerador, denominador, resultado_alternativo) devolve o terceiro argumento (ou vazio) quando o denominador é zero. Num filtro de loja sem pedidos, por exemplo.

✓
Exemplo

Faturamento R$ 100.000 e 500 pedidos → Ticket Médio = R$ 200. Margem: lucro R$ 30.000 ÷ faturamento R$ 100.000 = 30%.

05A mesma medida, perguntas diferentes

O mais importante da aula: a medida muda de resultado conforme o contexto do visual.

VisualEixo / LinhasValoresPergunta respondida
BarrasCadastroProdutos[Marca][Quantidade Vendida]Quais marcas saem mais?
ColunasCadastroProdutos[Categoria][Faturamento Total]Quanto cada categoria faturou?
RoscaCadastroClientes[Genero][Clientes]Quantos clientes de cada gênero compraram?
ColunasBaseVendas[ID Loja][Faturamento Total]Qual loja fatura mais?
TabelaCadastroProdutos[Produto][Lucro Total], [Margem %]Quais produtos dão mais lucro?
?
O que é contexto de filtro

Você escreveu Faturamento Total uma vez. Na barra da Apple, o Power BI filtra as vendas da Apple e soma; na barra da Dell, filtra a Dell. Cada barra, linha ou célula é um “contexto” diferente. É por isso que medidas são tão poderosas.

06Medida ou coluna? A regra de bolso

Coluna calculadaMedida
CalculaLinha por linha, ao atualizarNa hora, a cada filtro
Ocupa memóriaSimNão
Usa em eixo, legenda, segmentaçãoSimNão
Exemplos desta aulaPreço de Venda, Faturamento, Custo Total LinhaFaturamento Total, Lucro Total, Margem %, Ticket Médio
✓
Regra simples

Preciso de um valor para cada registro (ou para usar como categoria)? Coluna. Preciso somar, contar, comparar ou criar um indicador? Medida.

i

Na aula 6 você vai ver como calcular o faturamento direto numa medida com SUMX, sem criar colunas. É a forma mais profissional, mas entender a coluna antes facilita.

07Exercícios de fixação

A1 · As 8 medidas

Básico

Crie e formate: Quantidade Vendida, Quantidade de Pedidos, Clientes, Faturamento Total, Custo Total, Lucro Total, Margem % e Ticket Médio.

A2 · Cinco gráficos

Básico

Monte os cinco visuais da tabela “A mesma medida, perguntas diferentes” e escreva uma conclusão para cada um.

A3 · Cartões coloridos

Intermediário

Crie quatro cartões (Faturamento, Lucro, Pedidos, Clientes) e um quinto com o Ticket Médio. Use as cores sugeridas na aula 4.

A4 · Preço médio

Intermediário

Crie a medida Preço Médio = DIVIDE([Faturamento Total], [Quantidade Vendida]). Em qual categoria ele é maior? Faz sentido?

A5 · Itens por pedido

Desafio

Crie uma medida que mostre quantos itens, em média, cada pedido tem. Depois compare entre anos: os clientes estão comprando mais itens por pedido?

Dica

DIVIDE([Quantidade Vendida], [Quantidade de Pedidos]), num gráfico de colunas com o ano da Data da Venda.

08Resumo da aula

  • DAX é a linguagem de cálculo do Power BI; colunas sempre entre colchetes.
  • SUM soma; DISTINCTCOUNT conta valores únicos.
  • RELATED traz um valor da dimensão para a fato, seguindo o relacionamento.
  • DIVIDE divide sem erro de divisão por zero.
  • Coluna = linha a linha; medida = agregação que respeita o contexto do visual.
  • Próxima aula: tudo isso num dashboard completo, com SUMX, calendário e inteligência de tempo.
