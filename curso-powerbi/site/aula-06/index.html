03Parte 2 · Tratamento no Power Query

Três problemas reais: preço em texto com ponto decimal, cadastro de clientes com lixo no topo e vendas espalhadas em três arquivos.

Os preços estão gravados como texto no padrão americano: 25.95. Com o Windows em português, a detecção automática lê o ponto como separador de milhar e transforma 25.95 em 2595. O faturamento fica 100 vezes maior e nenhum erro aparece.

  1. Exclua a etapa automática Tipo Alterado (X ao lado da etapa).
  2. Selecione Preço Unitario, segure Ctrl e selecione Custo Unitario.

Botão direito sobre uma das colunas selecionadas → Alterar Tipo → Usando a Localidade…

Tipo de Dados: Número Decimal. Localidade: Inglês (Estados Unidos) → OK.

Agora aparecem 25,95 · 19,95 · 11,99. Remova também a coluna Observação (99% vazia) e defina SKU, Produto, Marca e Categoria como Texto.

M · etapa gerada
= Table.TransformColumnTypes(
    #"Cabeçalhos Promovidos",
    {{"Preço Unitario", type number}, {"Custo Unitario", type number}},
    "en-US"
)
?
Por quê

Esse é o tipo de erro que derruba a credibilidade de um analista: o painel fica lindo e o número está 100 vezes errado. Sempre confira valores conhecidos (preço de um produto) depois de converter tipos.

Página Inicial › Reduzir Linhas › Remover Linhas › Remover Linhas Superiores.

Digite 2 e clique em OK.

Transformar › Usar a Primeira Linha como Cabeçalho. Exclua a etapa automática de tipo que aparecer: ela converteria Documento em número e apagaria zeros à esquerda (ex.: 04013622223). Remova Column11 e Column12.

  • Documento → tipo Texto.
  • Data Nascimento vem como M/D/AAAA (4/8/1966): ícone de tipo › Usando a Localidade… › Data + Inglês (Estados Unidos).
  • ID Cliente e Num Filhos → Número Inteiro.

Botão direito em Genero › Substituir Valores: M → Masculino; repita F → Feminino. Em Estado Civil: C → Casado; S → Solteiro.

!
Atenção

Funciona porque a coluna só tem M ou F. Em colunas com texto livre, abra Opções avançadas e marque Coincidir conteúdo da célula inteira.

Selecione Primeiro Nome + Sobrenome › Adicionar Coluna › Mesclar Colunas › separador Espaço › nome Nome Completo.

Confira as Etapas Aplicadas e o Documento com zeros à esquerda preservados.

Selecione Vendas 2020 › Página Inicial › Acrescentar Consultas ▾ › Acrescentar Consultas como Novas. Marque Três ou mais tabelas, adicione Vendas 2021 e Vendas 2022 › OK. Renomeie Acrescentar1 para fVendas.

04Parte 3 · Modelagem em estrela

Uma fato no centro (fVendas) e dimensões em volta, relacionadas de 1 para muitos com filtro de direção única.

O Power BI detectou as chaves sozinho. Confira em Página Inicial › Gerenciar relações:

Se a detecção não ocorrer, arraste a coluna da fato até a chave da dimensão.

Exibição de Tabela › Nova tabela e cole:

DAX · tabela calculada
dCalendario =
VAR DataInicio = DATE ( YEAR ( MIN ( fVendas[Data da Venda] ) ), 1, 1 )
VAR DataFim = MAX ( fVendas[Data da Venda] )
RETURN
    ADDCOLUMNS (
        CALENDAR ( DataInicio, DataFim ),
        "Ano", YEAR ( [Date] ),
        "Mês Num", MONTH ( [Date] ),
        "Mês", FORMAT ( [Date], "mmm" ),
        "Ano-Mês", FORMAT ( [Date], "yyyy-mm" ),
        "Trimestre", "T" & QUARTER ( [Date] ),
        "Dia da Semana", FORMAT ( [Date], "ddd" ),
        "Dia Semana Num", WEEKDAY ( [Date], 2 )
    )
  1. Botão direito em dCalendario › Marcar como tabela de datas › coluna Date.
  2. Selecione a coluna Mês › Classificar por coluna › Mês Num; faça o mesmo com Dia da Semana por Dia Semana Num. Sem isso, os meses saem em ordem alfabética (abr, ago, dez…).
  3. Arraste fVendas[Data da Venda] até dCalendario[Date].
?
Por que terminar em 30/06/2022

A base 2022 só tem o 1º semestre. Encerrar o calendário na última venda faz o SAMEPERIODLASTYEAR comparar jan–jun/2022 com jan–jun/2021, e não com o ano inteiro.

Confira as três relações ativas, todas muitos-para-um a partir da fVendas.

05Parte 4 · Medidas DAX

Medidas numa tabela própria (_Medidas), organizadas em pastas de exibição.

Nova tabela: _Medidas = ROW("x", BLANK()) e oculte a coluna x. Selecione _Medidas › Nova medida:

DAX
Faturamento Total =
SUMX (
    fVendas,
    fVendas[Qtd Vendida] * RELATED ( dProdutos[Preço Unitario] )
)
?
SUMX em vez de coluna calculada

Na aula 5 você criou colunas de preço e faturamento. Aqui, SUMX percorre a fVendas linha a linha, multiplica a quantidade pelo preço buscado com RELATED e soma, tudo dentro da medida. O modelo fica mais leve: nenhuma coluna nova é gravada.

Formato: Moeda R$, 2 casas.

DAX · 1. Financeiro
Custo Total =
SUMX ( fVendas, fVendas[Qtd Vendida] * RELATED ( dProdutos[Custo Unitario] ) )

Lucro Total = [Faturamento Total] - [Custo Total]

Margem % = DIVIDE ( [Lucro Total], [Faturamento Total] )

Ticket Médio = DIVIDE ( [Faturamento Total], [Nº Pedidos] )

% Faturamento s/ Total =
DIVIDE (
    [Faturamento Total],
    CALCULATE ( [Faturamento Total], ALLSELECTED ( dProdutos ) )
)

% Faturamento s/ Total calcula a participação de cada produto/categoria dentro do que está selecionado nas segmentações. ALLSELECTED ignora o filtro da linha do visual, mas respeita os filtros externos (ano, marca).

DAX · 2. Volume
Qtd Vendida = SUM ( fVendas[Qtd Vendida] )

Nº Pedidos = DISTINCTCOUNT ( fVendas[Ordem de Compra] )

Clientes Ativos = DISTINCTCOUNT ( fVendas[ID Cliente] )

Lojas Ativas = DISTINCTCOUNT ( fVendas[ID Loja] )
DAX · 3. Inteligência de Tempo
Faturamento Mês Anterior =
CALCULATE ( [Faturamento Total], DATEADD ( dCalendario[Date], -1, MONTH ) )

Crescimento % Mensal =
DIVIDE ( [Faturamento Total] - [Faturamento Mês Anterior], [Faturamento Mês Anterior] )

Faturamento Ano Anterior =
VAR UltimoAno = MAX ( dCalendario[Ano] )
VAR DatasAno =
    CALCULATETABLE (
        VALUES ( dCalendario[Date] ),
        KEEPFILTERS ( dCalendario[Ano] = UltimoAno )
    )
RETURN
    CALCULATE ( [Faturamento Total], SAMEPERIODLASTYEAR ( DatasAno ) )

Crescimento YoY % =
VAR UltimoAno = MAX ( dCalendario[Ano] )
VAR FatAtual =
    CALCULATE ( [Faturamento Total], KEEPFILTERS ( dCalendario[Ano] = UltimoAno ) )
RETURN
    DIVIDE ( FatAtual - [Faturamento Ano Anterior], [Faturamento Ano Anterior] )

Faturamento Acumulado (YTD) =
TOTALYTD ( [Faturamento Total], dCalendario[Date] )
?
Por que o YoY usa o “último ano em contexto”

Sem filtro de ano, um SAMEPERIODLASTYEAR simples desloca o período inteiro e devolve +369%, um número sem sentido. Fixando o último ano visível, o cartão mostra jan–jun/2022 contra jan–jun/2021 (+564,8%) e, com o filtro em 2021, 2021 contra 2020 (+174,0%).

i

Notebook + Celular = 78% do faturamento. Mouse é o campeão de unidades, mas fatura pouco. Por que importa: volume e valor contam histórias diferentes; estoque se planeja por unidades, meta financeira por faturamento.

Marcas e clientes

  • Apple sozinha responde por 29% do faturamento (R$ 4,45 Mi), seguida de Asus (1,44), LG (1,42), Samsung (1,35), Dell (1,32) e HP (1,29). Dependência de um fornecedor é risco.
  • 17.416 clientes compraram. Gênero equilibrado: Masculino R$ 7,72 Mi (50,7%) e Feminino R$ 7,51 Mi (49,3%).
  • Casados faturam mais (R$ 7,98 Mi), mas solteiros têm ticket maior (R$ 637,66 contra R$ 578,21).
  • Ticket médio cai de R$ 628 (superior completo) para R$ 504 (médio incompleto).

Tendência e pontos de atenção

  • Virada em jul/2021: o faturamento mensal saiu de cerca de R$ 0,2 Mi para R$ 1,3 Mi em dez/2021. Melhor mês da série: jun/2022, com R$ 1.416.677,89.
  • Vestuário (Casaco e Camisa, marca Hashtag) tem margem de 56–58%, quase 20 pontos abaixo dos eletrônicos.
  • Ticket médio caiu de R$ 830 (2020) para R$ 596 (2022): mais pedidos com itens de menor valor (mouse, teclado).

09Atividades

A1 · Bata os números

Básico

Confira se os seus cartões batem com a tabela de gabarito da Parte 4. Se algum não bater, descubra a causa e escreva qual era.

A2 · Top 5 produtos

Básico

Na tabela “Ranking de Produtos”, aplique um filtro N superior = 5 por Faturamento Total.

A3 · Margem por marca

Intermediário

Crie um gráfico de barras com Marca e Margem %, ordenado do maior para o menor. Qual marca é a mais rentável? E a menos?

A4 · Página de produtos

Intermediário

Crie uma terceira página “Produtos” com: segmentação de categoria, matriz Categoria → Produto com Faturamento, Lucro e Margem, e um gráfico de dispersão Qtd Vendida × Margem % por produto.

A5 · Relatório executivo

Entrega

Escreva 5 conclusões sobre o negócio (cada uma com um número do painel) e 2 recomendações para a diretoria. Apresente em 3 minutos usando o dashboard.

10Resumo da aula

  • Converta preços em texto com Usando a Localidade e confira valores conhecidos.
  • Remova lixo do topo, promova cabeçalhos e mantenha documentos como texto.
  • Uma fato (fVendas) cercada de dimensões: o modelo estrela.
  • dCalendario marcada como tabela de datas, com meses classificados por número.
  • SUMX + RELATED calculam o faturamento sem colunas extras.
  • Tema JSON e grade de layout dão cara profissional ao painel.
