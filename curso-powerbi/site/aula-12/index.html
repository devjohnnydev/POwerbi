Um relatório que conversa com o usuário: interatividade e storytelling

Você vai transformar o dashboard numa experiência de navegação: segmentações sincronizadas, interações sob controle, drill down, drill-through para uma página de detalhe, dicas de ferramenta personalizadas, indicadores, botões de menu, parâmetros de campo e formatação condicional.

01O mapa do relatório

Antes de criar botões, decida o caminho que o usuário vai percorrer.

?
Storytelling

Um bom relatório funciona como uma apresentação: a primeira página dá a resposta curta, as outras explicam o porquê, e o detalhe aparece só para quem pedir. O usuário nunca deve se perguntar “e agora, onde eu clico?”.

02Segmentações e interações

EstiloQuando usar
Lista suspensaMuitos itens (marcas, produtos); economiza espaço
Blocos (botões)Poucos itens (anos, gênero); 1 clique
Entre (intervalo)Datas e números (preço de… até…)
Relativo“Últimos 3 meses” em painéis atualizados todo dia

Em Formato → Configurações de segmentação: ative Seleção única quando a análise só faz sentido com um valor (ano das metas), e Mostrar opção “Selecionar tudo” nas listas.

  1. Copie a segmentação de Ano da Visão Geral e cole nas outras páginas. O Power BI pergunta se quer sincronizar: Sincronizar.
  2. Ou: Exibição → Sincronizar segmentações, selecione a segmentação e marque, para cada página, as colunas Sincronizar (o filtro vale lá) e Visível (aparece lá).
?
Por quê

O usuário escolhe 2021 na primeira página e espera continuar em 2021 ao navegar. Sem sincronizar, cada página fica num ano diferente e os números “não batem”.

Selecione um visual → Formato (faixa de opções) → Editar interações. Em cada um dos outros visuais aparecem ícones:

  • Filtrar (funil): o outro visual mostra só o selecionado;
  • Realçar (gráfico): mostra o selecionado em destaque e o resto apagado;
  • Nenhum (círculo cortado): o outro visual ignora o clique.

Exemplo: o cartão “Faturamento Total do Ano” não deve mudar quando você clica numa marca. Marque Nenhum nele.

03Hierarquias e drill down

No painel Dados, em dProdutos, clique com o botão direito em Categoria → Criar hierarquia. Arraste Marca e Produto para dentro dela. Renomeie para Hierarquia Produto.

Num gráfico de barras, coloque a hierarquia no eixo. Aparecem as setas no topo do visual:

ÍconeFaz
↓ (ativar drill down)Clique numa barra para descer só nela (Notebook → marcas de notebook)
⇊ (próximo nível)Desce todas as barras um nível (todas as marcas)
⑂ (expandir)Mostra categoria e marca juntas (Notebook Apple, Notebook Asus…)
↑ (voltar)Sobe um nível
?
Por quê

Um único gráfico responde três perguntas em sequência: qual categoria? qual marca dentro dela? qual produto? Economiza espaço e conduz a investigação.

04Drill-through: página de detalhe

Clique com o botão direito num produto e vá para uma página só dele.

  1. Nova página, renomeie para Detalhe do Produto.
  2. No painel Compilar (com a página selecionada, sem visual), na área Drill-through, arraste dProdutos[Produto].
  3. O Power BI cria automaticamente um botão Voltar no canto superior esquerdo.
  • Cartão com o título dinâmico: "Produto: " & SELECTEDVALUE(dProdutos[Produto]);
  • Cartões: Faturamento, Qtd Vendida, Margem %, Ranking Produto;
  • Linhas: Faturamento por Mês Ano;
  • Barras: Faturamento por Faixa Etária e por Genero (dClientes);
  • Tabela: últimos pedidos (Data, Ordem de Compra, Qtd).

Oculte a página (botão direito na aba → Ocultar página): ela só deve ser acessada pelo drill-through.

Na página Produtos, clique com o botão direito numa linha da tabela ou numa barra → Drill-through → Detalhe do Produto. A página abre filtrada naquele produto. O botão Voltar retorna (no Desktop, use Ctrl+clique nos botões).

?
Por quê

A página principal fica limpa; o detalhe existe para quem precisa. É assim que se atende ao diretor (quer o resumo) e ao comprador (quer o produto) no mesmo relatório.

05Dica de ferramenta personalizada

  1. Nova página Dica Produto → Formato da página → Informações da página → ative Permitir uso como dica de ferramenta.
  2. Configurações de tela → Tipo: Dica de ferramenta (320 × 240).
  3. Monte um mini painel: cartão Faturamento, cartão Margem %, minigráfico de linha por mês.
  4. Oculte a página.

Selecione o gráfico de produtos → Formato → Propriedades → Dica de ferramenta → Tipo: Página do relatório → Página: Dica Produto. Passe o mouse sobre uma barra: aparece o mini painel daquele item.

i

Na página de dica, em Dica de ferramenta do painel Compilar, coloque o campo Produto: a dica aparece automaticamente em qualquer visual que use Produto.

06Indicadores e botões

Alternar entre gráfico e tabela, e um menu de navegação de verdade.

Exibição → ative Seleção e Indicadores. O painel Seleção lista todos os objetos da página; o ícone de olho mostra/oculta. Renomeie os objetos com nomes claros (duplo clique): grafico_marcas, tabela_marcas.

  1. Coloque um gráfico de barras e uma tabela com os mesmos dados, um sobre o outro, do mesmo tamanho.
  2. Oculte a tabela (olho) → no painel Indicadores, Adicionar → renomeie para Ver Gráfico.
  3. Mostre a tabela e oculte o gráfico → Adicionar → Ver Tabela.
  4. Nos três pontinhos de cada indicador, desmarque Dados (para o indicador não congelar os filtros do usuário) e deixe Exibir e Visual selecionado conforme a necessidade.

Inserir → Botões → Em branco. Em Formato → Estilo → Texto “Gráfico”; Ação → Tipo Indicador → Ver Gráfico. Repita para “Tabela”.

i

Mais rápido: Inserir → Botões → Navegador → Navegador de indicadores cria os botões de todos os indicadores de um grupo.

Inserir → Botões → Navegador → Navegador de páginas. Ele cria um botão para cada página visível e destaca a página atual. Posicione numa faixa lateral do fundo (aula 8) e copie para todas as páginas.

07Parâmetros de campo

Um gráfico, várias medidas: o usuário escolhe o que quer ver.

Modelagem → Novo parâmetro → Campos. Nome: Métrica. Adicione: Faturamento Total, Lucro Total, Qtd Vendida, Nº Pedidos. Marque Adicionar segmentação a esta página → Criar.

O Power BI cria uma tabela com este DAX (você pode editar os rótulos):

DAX · tabela gerada
Métrica = {
    ("Faturamento", NAMEOF ( '_Medidas'[Faturamento Total] ), 0),
    ("Lucro",       NAMEOF ( '_Medidas'[Lucro Total] ), 1),
    ("Quantidade",  NAMEOF ( '_Medidas'[Qtd Vendida] ), 2),
    ("Pedidos",     NAMEOF ( '_Medidas'[Nº Pedidos] ), 3)
}

Num gráfico de colunas por Mês Ano, coloque o campo Métrica no eixo Y. Clique nos botões da segmentação: o gráfico troca de medida. Faça o mesmo com um segundo parâmetro de campos para o eixo (Categoria, Marca, Faixa Etária).

?
Por quê

Em vez de 4 gráficos quase iguais, um gráfico flexível. A página fica limpa e o usuário explora sozinho.

08Formatação condicional

Gráfico de barras por Marca com Margem %. Formato → Barras → Cor → botão fx → Estilo: Regras: se valor < 0,65 → vermelho; 0,65 a 0,75 → amarelo; ≥ 0,75 → verde.

Na tabela de produtos: em Faturamento Total → Formatação condicional → Barras de dados; em Var. % Anual → Ícones. A tabela vira um mini gráfico, sem ocupar mais espaço.

DAX
Cor Margem =
SWITCH ( TRUE (), [Margem %] >= 0.75, "#10B981", [Margem %] >= 0.65, "#F59E0B", "#EF4444" )

No fx da cor, Estilo de formato: Valor do campo → Cor Margem. A vantagem: a regra fica num lugar só e vale para vários visuais.

10Atividades

A1 · Interações

Básico

Na Visão Geral, configure para que os cartões de KPI não sejam filtrados pelo gráfico de marcas, mas sejam filtrados pelas segmentações.

A2 · Drill-through de cliente

Intermediário

Crie a página oculta “Detalhe do Cliente” com drill-through por dClientes[Nome Completo]: compras por mês, produtos comprados, primeira e última compra (aula 9).

A3 · Dica de ferramenta

Intermediário

Crie uma página de dica para o gráfico de marcas mostrando as 3 categorias mais vendidas daquela marca.

A4 · Menu lateral

Intermediário

Use o fundo da aula 8 com uma faixa lateral e crie um navegador de páginas com ícones (Inserir → Imagem com ação de Navegação de página).

A5 · Roteiro de apresentação

Entrega

Monte uma sequência de 4 indicadores que conte uma história (“1. A empresa cresceu muito; 2. o crescimento veio de notebooks; 3. mas a margem do vestuário é baixa; 4. recomendação”). Apresente em 3 minutos usando o modo Exibição de leitura.

11Resumo da aula

  • Desenhe o caminho do usuário antes de criar botões.
  • Sincronize segmentações; use Editar interações para controlar filtros cruzados.
  • Hierarquias com drill down economizam espaço.
  • Drill-through e dicas de ferramenta mostram o detalhe só para quem pede.
  • Indicadores + botões + navegador criam a experiência de aplicativo.
  • Parâmetros de campo e formatação condicional deixam o usuário explorar e enxergar o que importa.
